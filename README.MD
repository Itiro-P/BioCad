# Atividade princípios SOLID.

Este branch contém a entrega da atividade de princípios SOLID para a disciplina de Engenharia de Software.

A pasta `examples` contém os exemplos explicados de forma mais detalhada.

## Visão Geral

BioCad foi feito para o trabalho final da disciplina de Análise e Projeto de Software. O intuito aqui é entender como os princípios SOLID + Demeter e composição vs herança são aplicados na prática.
